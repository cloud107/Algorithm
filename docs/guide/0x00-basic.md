2. 分治法求等比数列和:
    - c为奇数时
    $$
    \begin{aligned}
    sum(p,c)&=(1+p+...+p^{\frac{c-1}{2}})+(p^{\frac{c+1}{2}}+...+p^c) \\
            &=(1+p+...+p^{\frac{c-1}{2}})(1+p^{\frac{c-1}{2}})\\
            &=sum(p,\frac{c-1}{2})*(1+p^{\frac{c-1}{2}})
    \end{aligned}
    $$
    - c为偶数时
    $sum(p,c)=sum(p,\frac{c}{2})*(1+p^{\frac{c}{2}-1})+p^c$

# 前缀和与差分
1. 一维前缀和 $S[i]=\sum_{j=1}^{i}A[j],S[i]=\sum_{i-1}+A[i],\sum_{i=l}^{r}=S[r]-S[l]$
2. 二维前缀和 $S[i][j]=\sum_{x=1,y=1}^{i,j}A[x][y],S[i][j]=-S[i-1][j-1]+S[i][j-1]+S[i-1][j]+A[i][j],\sum_{i=lx,j=lx}^{rx,ry}=S[rx][lx]-S[rx][ly]-S[lx][ry]+S[lx][ly]$
3. 差分能将区间操作转换成节点操作

```
void find(int q)
{
    int l = 0, r = n + 1;//开区间
```

# 排序
1. 离散化:题设的定义域可能很大,但是实际涉及的值只占较小的一部分,此时将数组排序去重后映射成从一开始的自然数索引
```
void discrete()
{
    sort(a+1,a+n+1);
    for(int i=1;i<=n;i++) //可以用unique函数+erase来代替,但需要用vector容器,这时query函数需要重写
    {
        if(i==1 || a[i]!=a[i-1])
            b[++m] = a[i];
    }
}
int query(int x)
{
    return lower_bound(b+1,b+1+n,x) - b;
}

```
2. 经典问题--均分纸牌:M个人站成一排,每个人手中有c[1]~c[M]张牌,一次操作中,每个人可以把一张牌给旁边的人,问最少经过多少次操作能使所有人的牌相等.题解:从第一个人开始考虑,若大于平均值就把多的牌给右边的人,若小于平均值就把差的牌从右边的人手中拿来,依次往后考虑.
此时
$ ans=\sum_{i=1}^{M}|i*Avg-G[i]| $ , 其中Avg为数组的平均值,G为前缀和数组
将数组的每一个值减去Avg得到A数组,化简为
$ ans=\sum_{i=1}^{M}|S[i]| $ , 其中S是数组A的前缀和数组
扩展:若M个人围成一圈,第一个人不仅能和右边的人交互,还能和左边的人交互,这时最优方案一定会有两个人之间没有卡牌交换,可以枚举总第k个人后将环断开,这时纸牌数和前缀和为
$$
\begin{aligned}
A[k+1]  \qquad S[k+1]-S[k]  \\
A[k+2]  \qquad S[k+2]-S[k]  \\
....\\
A[M]  \qquad \qquad \ \ S[M]-S[k]  \\
A[1]  \qquad S[1]+S[M]-S[k]  \\
...  \\
A[k]  \qquad S[k]+S[M]-S[k]  \\
\end{aligned}
$$
$ans=\sum_{i=1}^{M}|S[i]-S[k]|$

这时涉及到另一个经典问题仓库选择,当k选为S数组的中位数时,ans最小

3. 快排思想求第k大的数,每次选一个基准值,统计出大于基准值的个数cnt,若k<=cnt,在大于基准值的数中继续找第k大的数,若k>cnt,在小于或等于基准值的数中找第k-cnt大的数,此时时间复杂度为$O(N)$
4. 归并排序思想求逆序对,当左半段数组的第i个数小于等于右半段的第j个数时,不构成逆序对,否则逆序对的个数为mid-i+1(mid~j-1部分在枚举左半段1~i-1时已经统计过了)
5. 冒泡排序的本质是一次交换减少一个逆序对
6. 奇数码问题,只记结论:若两个奇数码一维化后的数组逆序对个数的奇偶性相同则可达

# 倍增
1. 由于每一个数都能分解成若干个2的次幂项之和.当线性递推的时间复杂度不被允许时,可以用倍增递推的方式,只递推2的整数次幂位置,当需要其他位置的值时,将这个位置分解成"若干个2的次幂项之和".
2. 重排序不等式:对于两个递增数组a和b
$\sum_{i=1}^{n}a[i]*b[n-i+1] <= \sum_{i=1}^{n}a[i]*b[π(i)] <= \sum_{i=1}^{n}a[i]*b[i]$
即 逆序配对 <= 乱序配对 <= 顺序配对
由此可以得出一个推论:
当从一个数组中每次取两个数求差平方,最后求和,如何使答案最大化?每次取最大值和最小值.
3. ST算法:在一个数组中每次给出l和r,要求在线求解A[l]到A[r]的最大值(RMQ问题).
用一个数组$F[i][j]$表示A中下标在子区间$[i,i+2^j-1]$里的最大值,先预处理出F数组
```
void ST_prewok(){
    for(int i = 1;i<=n;i++) f[i][0] = a[i];
    int t = log(n) / log(2) + 1;
    for(int j = 1;j < t;j++)
    {
        for(int i = 1;i<=n - (1<<j) + 1;i++)
        {
            f[i][j] = max(f[i][j-1],f[i+(1<<j-1)][j-1]);
        }
    }
}
```
对于[l,r]区间的最大值时,先求出一个k,使得$2^k < r-l+1 <= 2^{k+1}$ 这是区间最大值等于f[l][k]和f[r-(1<<k)+1][k]中较大者,因为这两个值能覆盖[l,r]区间而不包括区间之外的值.
```
int ST_query(int l ,int r)
{
    int k = log(r-l+1) / log(2);
    return max(f[l][k] , f[r-(1<<k)+1][k]);
}
```
