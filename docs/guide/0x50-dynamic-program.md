# 线性DP

1. LIS问题(最长上升子序列)
    1. 朴素DP解法:
        - 状态表示: F[i]表示以A[i]为结尾的最长上升子序列的长度
        - 状态转移: F[i] = max{F[j]} + 1, 其中j < i且A[j] < A[i]
        - 边界: F[0] = 0
        - 目标: $\max_{1 \leq i \leq n} F[i] $
    2. 二分优化版:
        - 维护一个数组tail，其中tail[i]表示长度为i的最长上升子序列的最后一个元素的最小值
        - 遍历数组A，对于每个元素A[i]，如果A[i] > tail[last]，则直接更新tail[last + 1] = A[i]
        - 否则，使用二分查找在tail中找到第一个大于等于A[i]的位置pos，并更新tail[pos] = A[i]
        - 最终答案为tail数组的长度

2. LCS问题(最长公共子序列)
    - 状态表示: F[i][j]表示A的前i个字符和B的前j个字符的最长公共子序列的长度
    - 状态转移: 
        - 如果A[i] == B[j], 则F[i][j] = F[i-1][j-1] + 1
        - 否则, F[i][j] = max(F[i-1][j], F[i][j-1])
    - 边界: F[0][j] = 0, F[i][0] = 0
    - 目标: F[n][m]

3. 数字三角形
    - 状态表示: F[i][j]表示从三角形顶部到第i行第j列的最大路径和
    - 状态转移: F[i][j] = max(F[i-1][j], F[i-1][j-1]) + A[i][j]
    - 边界: F[1][1] = A[1][1]
    - 目标: $\max_{1 \leq j \leq n} F[n][j]$

#### P10954 LCIS
- 来源: 洛谷
- 题意: 给定两个长度为n的序列A和B,求最长公共上升子序列的长度
- 核心思路
    - 用F[i][j]表示A的前i个元素和B的前j个元素的以B[j]结尾的最长公共上升子序列的长度
    - 转移方程:
        - 如果A[i] == B[j], 则F[i][j] = max{F[i-1][k]} + 1, 其中k < j且B[k] < B[j],即B[k] < A[i] (这里有一个优化技巧,可以在内层循环中维护一个变量val来记录满足条件的最大F[i-1][k]的值,避免每次都要遍历一遍)
        - 否则, F[i][j] = F[i-1][j]
- 核心代码:
```
for(int i = 1;i<=n;i++) {
    int val = 0;
    for(int j = 1;j<=n;j++) {
        if(a[i]==b[j]) f[i][j] = val+1;
        else f[i][j] = f[i-1][j];
        if(b[j]<a[i]) val = max(val,f[i-1][j]);
    }
}
int ans = 0;
for(int i = 1; i<=n;i++)ans=max(ans,f[n][i]);
```

#### SP703 SERVICE - Mobile Service
- 来源: 洛谷
- 题意: 一个公司有三个服务员,初始时分别在位置1,2,3处,给出N个请求,每个请求需要一个服务员去到指定位置,每次移动需要花费代价c(p,q),任何时刻不允许两个服务员在同一个位置,求完成所有请求的最小代价
- 核心思路
    - 阶段是每个请求,状态是三个服务员的位置,转移是选择哪个服务员去完成当前请求
    - 很自然地想到用F[i][p1][p2][p3]表示完成前i个请求后,三个服务员分别在位置p1,p2,p3的最小代价,**但是很显然处理完第i个请求时必定有一个服务员在位置qi处,四个变量有必定有一个是多余的**,所以我们用F[i][p1][p2]表示完成前i个请求后,三个服务员分别在位置p1,p2,qi处的最小代价,这样就将状态空间从O(n*m^3)缩小到了O(n*m^2),其中m是位置的数量
    - 转移方程: 
    F[i][x][y] = min(F[i][x][y], F[i-1][x][y] + c(p(i-1),pi))
    F[i][p(i-1)][y] = min(F[i][p(i-1)][y], F[i-1][x][y] + c(x,pi))
    F[i][x][p(i-1)] = min(F[i][x][p(i-1)], F[i-1][x][y] + c(y,pi))
- 核心代码:
```
    f[0][1][2] = 0;
    x[0] = 3;
    for(int i = 1; i<=n;i++) {
        for(int j = 1; j<=l; j++) {
            for(int k = 1; k<=l; k++) {
                if(j==k||x[i-1]==j||x[i-1]==k) {
                    // f[i][j][k] = f[i-1][j][k];
                    continue;
                }
                f[i][j][k] = min(f[i][j][k],f[i-1][j][k]+c[x[i-1]][x[i]]);
                f[i][x[i-1]][k] = min(f[i][x[i-1]][k],f[i-1][j][k]+c[j][x[i]]);
                f[i][j][x[i-1]] = min(f[i][j][x[i-1]],f[i-1][j][k]+c[k][x[i]]);//要长脑子了
            }
        }
    }
    int ans = INT_MAX;
    for(int i = 1;i<=l;i++) {
        for(int j = 1;j<=l;j++) {
            ans=min(ans,f[n][i][j]);
            // cout<<f[n][i][j]<<endl;
        }
    }
```

# 背包问题

1. 01背包
    - 状态表示: F[i][j]表示前i件物品在容量为j的背包中的最大价值
    - 阶段划分: 正在处理第i件物品,已经处理了前i-1件物品
    - 状态转移: F[i][j] = max(F[i-1][j], F[i-1][j-w[i]] + v[i]) (如果j >= w[i])
    - 边界: F[0][0] = 0, 其余均为负无穷
    - 目标: F[n][W]
    - 阶段是单调向前的,可以优化空间复杂度为O(W),从后往前更新F[j],因为在更新i阶段的F[j]时,需要用到i-1阶段的F[j]和F[j-w[i]],如果从前往后更新,则会覆盖掉i-1阶段的F[j-w[i]],导致结果错误
    ```
        memset(f,0xcf,sizeof(f));
        f[0] = 0;
        for(int i = 1;i<=n;i++) {
            for(int j = m;j>=v[i];j--) {
                f[j] = max(f[j],f[j-v[i]]+w[i]);
            }
        }
        int ans = 0;
        for(int j = 0; j<=m; j++) ans = max(ans,f[j]);
    ```
2. 完全背包
    - 状态表示: F[i][j]表示前i件物品在容量为j的背包中的最大价值
    - 阶段划分: 正在处理第i件物品,已经处理了前i-1件物品
    - 状态转移: F[i][j] = max(F[i-1][j], F[i][j-w[i]] + v[i]) (如果j >= w[i])
    - 边界: F[0][0] = 0, 其余均为负无穷
    - 目标: F[n][W]
    - 阶段是单调向前的,可以优化空间复杂度为O(W),从前往后更新F[j],因为在更新i阶段的F[j]时,需要用到i阶段的F[j-w[i]],如果从后往前更新,则相当于在更新i阶段的F[j]时,用到了i-1阶段的F[j-w[i]],导致结果错误

#### UVA323 Jury Compromise
- 来源: UVA
- 题意: 给定n个物品,每个物品有两个属性a和b,从中选出m个物品使得$\sum a$和$\sum b$的差的绝对值最小,如果有多组方案满足这个条件,则选择$\sum a + \sum b$较大的方案
- 核心思路
    - 首先明确这是一个01背包
    - 用F[i][j]表示前i个物品中选出一些物品使得$\sum a - \sum b = j$的最大$\sum a + \sum b$
    - 转移方程: F[i][j] = max(F[i-1][j], F[i-1][j-(a[i]-b[i])] + a[i] + b[i]) (如果j >= a[i]-b[i])
    - 边界: F[0][M] = 0, 其余均为负无穷,其中M是所有物品的a和b的差的绝对值的最大值,为了避免负数下标,我们把j的范围从[-M,M]映射到[0,2M],即j' = j + M
    - 目标: 在F[n][j]中找到满足|j-M|最小的j,如果有多个满足条件的j,则选择F[n][j]最大的那个j
    - 注意这个问题中a[i]-b[i]的值可能为负数,所以不能简单地用滚动数组从后往前更新
    - 这道题还要求输出选中的物品的编号,所以我们需要维护一个path数组来记录每个状态是由哪个状态转移过来的,这样在找到最终答案后就可以通过回溯的方式输出选中的物品的编号了
- 核心代码:
```
    memset(f,-1,sizeof(f));
    f[0][M] = 0;
    for(int k = 1; k<=n; k++) {
        for(int i = m; i>=1;i--) {
            for(int j = 0; j<2*M;j++) {
                //f[i][j] = max(f[i][j],f[i-1][j-sub[k]] + sum[k])
                if(j-sub[k] < 0 || j-sub[k] >2*M) continue;
                if(f[i-1][j-sub[k]]<0) continue;
                if(f[i][j] < f[i-1][j-sub[k]] + sum[k]) {
                    f[i][j] = f[i-1][j-sub[k]] + sum[k];
                    path[i][j] = path[i-1][j-sub[k]];
                    path[i][j].push_back(k);
                }
            }
        }
    }
    int i;
    for(i=0;f[m][M-i]==-1&&f[m][M+i]==-1;i++);
    int temp = f[m][M-i] > f[m][M+i] ? -i : i;
    int D = (f[m][M+temp] + temp) / 2;
    int P = (f[m][M+temp] - temp) / 2;
```

区间DP的一大特点就是阶段划分一般是区间的长度,状态表示一般是区间的左右端点,转移方程一般是枚举区间内的一个点作为分割点,把区间分成两部分,然后根据题意把两部分的结果合并起来

#### P1775 石子合并（弱化版）
- 来源: 洛谷
- 题意: 给定n堆石子,每堆有a[i]个石子,每次只能合并两堆石子,合并的代价是两堆石子数量的和,求把所有石子合并成一堆的最小代价
- 核心思路
    - 用f[l][r]表示把从l开始到r的区间内的石子合并成一堆的最小代价
    - 转移方程: f[l][r] = min(f[l][k] + f[k+1][r] + sum[l][r]) (其中l <= k < r, sum[l][r]表示从l到r的石子数量的和,sum可以用前缀和预处理出来)
    - 初值: f[i][i] = 0 (只有一堆石子不需要合并,所以代价为0)
- 核心代码
```
    for(int len = 2;len<=n;len++) {
        for(int l = 1; l<=n; l++) {
            int r = l+len-1;
            if(r>n) continue;
            for(int k = l;k<r;k++) {
                f[l][r] = min(f[l][r],f[l][k]+f[k+1][r] + sum[r]-sum[l-1]);
            }
        }
    }
```

#### P4342 [IOI 1998] Polygon
- 来源: 洛谷
- 题意: 给定一个n边形,每条边表示一个运算符加号或乘号,每个顶点表示一个数字,第一步,玩家要断开一条边,第接下来玩家每次选择一条边,按运算符合并两个端点,直到剩下一个数字为止,求玩家能得到的最大值
- 核心思路
    - 由于题目说要先断开一个点,容易想到我们可以直接枚举断开的边,但这样时间复杂度太高,我们可以将这个多边形看成一个链,再将这个链复制一份拼接在后面,这样就将这个多边形转化为一个长度为2n的链,我们只需要枚举区间长度为n的区间即可,这样时间复杂度就从O(n^4)降低到了O(n^3),类似的环形的题目也可以考虑这种方法
    - 用f[l][r][0]表示从l到r的区间内的数字能得到的最大值,用f[l][r][1]表示从l到r的区间内的数字能得到的最小值
    - 初值: f[i][i][0] = f[i][i][1] = a[i] (区间内只有一个数字,最大值和最小值都等于这个数字)
    - 转移方程:
        - 如果边界l和r之间的运算符是加号,则f[l][r][0] = max(f[l][r][0], f[l][k][0] + f[k+1][r][0]), f[l][r][1] = min(f[l][r][1], f[l][k][1] + f[k+1][r][1])
        - 如果边界l和r之间的运算符是乘号,则最大值最小值的计算比较麻烦,需要考虑四种情况:
            - f[l][r][0] = max(f[l][r][0], f[l][k][0] * f[k+1][r][0])
            - f[l][r][0] = max(f[l][r][0], f[l][k][0] * f[k+1][r][1])
            - f[l][r][0] = max(f[l][r][0], f[l][k][1] * f[k+1][r][0])
            - f[l][r][0] = max(f[l][r][0], f[l][k][1] * f[k+1][r][1])
            - f[l][r][1] = min(f[l][r][1], f[l][k][0] * f[k+1][r][0])
            - f[l][r][1] = min(f[l][r][1], f[l][k][0] * f[k+1][r][1])
            - f[l][r][1] = min(f[l][r][1], f[l][k][1] * f[k+1][r][0])
            - f[l][r][1] = min(f[l][r][1], f[l][k'][1] * f[k+1'][r'][1])
- 核心代码:
```
    for(int i=1;i<=(n<<1);i++){
        for(int j=1;j<=(n<<1);j++){
            if(i==j) continue;
            f[i][j][0]=-INF,f[i][j][1]=INF;
        }
    }
    for(int len = 2; len<=n; len++) {
        for(int l = 1; l<=2*n; l++) {
            int r = l+len-1;
            if(r>2*n) continue;

            for(int k = l;k<r;k++) {
                if(op[k+1]=='t') {
                    f[l][r][0] = max(f[l][r][0],f[l][k][0] + f[k+1][r][0]);
                    f[l][r][1] = min(f[l][r][1],f[l][k][1] + f[k+1][r][1]);
                    
                }
                else {
                    int maxd=INT_MIN,mind=INT_MAX;
                    maxd = max(maxd,f[l][k][0] * f[k+1][r][0]);
                    maxd = max(maxd,f[l][k][1] * f[k+1][r][0]);
                    maxd = max(maxd,f[l][k][0] * f[k+1][r][1]);
                    maxd = max(maxd,f[l][k][1] * f[k+1][r][1]);
                    mind = min(mind,f[l][k][0] * f[k+1][r][0]);
                    mind = min(mind,f[l][k][1] * f[k+1][r][0]);
                    mind = min(mind,f[l][k][0] * f[k+1][r][1]);
                    mind = min(mind,f[l][k][1] * f[k+1][r][1]);
                    f[l][r][0] = max(maxd,f[l][r][0]);
                    f[l][r][1] = min(mind,f[l][r][1]);
                }
            }
        }
    }

    int ans = INT_MIN;
    for(int l = 1;l<=n;l++) {
        int r = l+n-1;
        ans = max(ans,f[l][r][0]);
    }
```


# 树形DP
树形DP的核心思路是把树看成一个有根树,然后用DFS的方式从叶子节点开始往上计算每个节点的状态,每个节点的状态可以根据它的子节点的状态来计算出来,这样就可以避免重复计算,提高效率,DP状态的第一维往往是节点编号,第二维往往是一些与题意相关的状态,比如选不选这个节点,或者这个节点的某个属性等等

### 刷题笔记
#### P1352 没有上司的舞会
**树形DP究极经典**
- 来源: 洛谷
- 题意: 给定一个树,每个节点有一个权值,从中选出一些节点,条件是选了父节点就不能选子节点,求选出的节点的权值之和的最大值
- 核心思路
    - 用F[u][0]表示不选节点u的情况下,以u为根的子树中能得到的最大权值和,用F[u][1]表示选节点u的情况下,以u为根的子树中能得到的最大权值和
    - 转移方程: 
        - F[u][0] = sum(max(F[v][0], F[v][1])) (其中v是u的子节点,如果不选u,则v可以选也可以不选,取两者的最大值)
        - F[u][1] = w[u] + sum(F[v][0]) (其中v是u的子节点,如果选了u,则v不能选,只能取F[v][0])
- 核心代码:
```
void dfs(int x,int pre) {
    f[x][0] = 0;
    f[x][1] = a[x];
    for(int i = head[x];i;i=nex[i]) {
        int y = ver[i];
        if(y==pre) continue;
        dfs(y,x);
        f[x][0] += max(f[y][0],f[y][1]);
        f[x][1] += f[y][0];
    }
}
```

#### P2014 [CTSC1997] 选课
- 来源: 洛谷
- 题意: 给定n门课程,每门课程有一个学分和一些先修课程,选课的条件是如果选了某门课程,则必须选它的先修课程,求选择m门课最多能获得多少学分
- 核心思路
    - 这是一个背包类的树形DP,用f[x][t]表示以课程x为根的子树中选t门课能获得的最大学分和
    - 转移方程: f[x][t] = max(f[x][t], f[x][t-k] + f[y][k]) (其中y是x的子节点, k是从0到t的一个变量,表示在子树y中选k门课)
    - 因为根据题目给出的可能是一个森林,所以我们用一个虚拟节点0连接所有的根节点,这样就把森林转化成了一棵树,我们只需要计算f[0][m]即可
- 核心代码:
```
void dfs(int x,int pre) {
    for(int i = head[x];i;i=nex[i]) {
        int y = ver[i];
        if(y==pre) continue;
        dfs(y,x);
        for(int j = m; j>=0; j--) {
            for(int k = j; k>=0; k--) {
                if(j-k<0) continue;
                f[x][j] = max(f[x][j],f[x][j-k] + f[y][k]);
            }
        }
    }
    if(x) {
        for(int i = m; i>0;i--) {
            f[x][i] = f[x][i-1] + a[x];
        }
    }
    
}
```

# 环形与后效性处理

解决环形问题的两种常用方法:
1. 线性化: 将环形问题转化为线性问题,比如把一个长度为n的环复制一份拼接在后面,这样就得到了一个长度为2n的链,我们只需要枚举区间长度为n的区间即可,这样时间复杂度就从O(n^4)降低到了O(n^3),类似的环形的题目也可以考虑这种方法
2. 两次dp法: 直接选一条边断开,把环断开成一个链,然后处理这个链,第二次强行把这个边接上,处理这个链,最后取两者的结果即可

### 刷题笔记
#### P6064 [USACO05JAN] Naptime G
- 来源: 洛谷
- 题意: 在某个星球上一天有n个小时,一头奶牛一天睡m个小时,每个小时睡觉能恢复a[i]的精力,奶牛开始睡的第一个小时不能恢复精力,而且奶牛每天睡眠时间固定,所以说如果前一天的最后一个小时睡觉了,那么第二天的第一个小时就能恢复精力了,求奶牛一天能恢复的最大精力
- 核心思路
    - 我们用f[i][j][0]表示前i个小时睡了j个小时且第i个小时没睡觉能恢复的最大精力,f[i][j][1]表示前i个小时睡了j个小时且第i个小时睡觉能恢复的最大精力
    - 转移方程:
        - f[i][j][0] = max(f[i-1][j][0], f[i-1][j][1]) (如果第i个小时没睡觉,那么前一个小时无论睡不睡觉都可以)
        - f[i][j][1] = max(f[i-1][j-1][0], f[i-1][j-1][1]) + a[i] (如果第i个小时睡觉了且前一个小时也睡觉了,才能恢复精力)
    - 由于环形的缘故,我们需要两次dp,第一次假设最后一个小时没睡觉,第二次假设最后一个小时睡觉了,最后取两者的结果即可

- 核心代码:
```
    memset(f,0xcf,sizeof(f));

    f[1][0][0] = f[1][1][1] = 0;
    for(int i = 2; i<=n; i++) {
        for(int j = b;j>=0; j--) {
            f[i][j][0] = max(f[i-1][j][0],f[i-1][j][1]);
            f[i][j][1] = max(f[i-1][j-1][0],f[i-1][j-1][1] + a[i]);
        }
    }
    ans = f[n][b][0];
    // cout<<ans<<endl;
    memset(f,0xcf,sizeof(f));
    f[1][0][0] = 0;
    f[1][1][1] = a[1];
    for(int i = 2; i<=n; i++) {
        for(int j = b;j>=0; j--) {
            f[i][j][0] = max(f[i-1][j][0],f[i-1][j][1]);
            f[i][j][1] = max(f[i-1][j-1][0],f[i-1][j-1][1] + a[i]);
        }
    }
    ans = max(ans,f[n][b][1]);
```

#### P10957 环路运输
- 来源: 洛谷
- 题意: 有一条环形公路均匀地分布着n个仓库,每个仓库有a[i]个货物,两个仓库间的运输成本定义为a[i]+a[j]+abs(i-j),求出运输成本最大的两个仓库
- 核心思路
    - 将a[i]-i看成一个新的数组b[i],再把b数组复制拼接在尾部,这样计算两个仓库i和j的运输成本就变成了b[i]+b[j]+2*i(i>j),我们只需要枚举i和j的距离不超过n/2+1的情况即可,因为如果距离超过n/2+1,则可以反过来计算,这样就避免了环形的问题
    - 用单调队列维护一个窗口内的最大值,窗口大小为n/2+1,这样就可以在O(n)的时间复杂度内找到每个i对应的j使得b[i]+b[j]+2*i最大了
- 核心代码:
```
    for(int i = 1;i<=n;i++) {
        cin>>a[i];
        a[i] -= i;
        a[i+n] = a[i] - n;
    }

    len = n/2+1;
    for(int i = 1; i<=2*n; i++) {
        while(l<r && qu[l]<=i-len) l++;
        ans = max(ans,a[i]+i+i+a[qu[l]]);
        while(l<r && a[qu[r]]<=a[i]) r--;
        qu[++r]=i;
    }
```
