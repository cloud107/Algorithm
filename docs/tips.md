# 编译与运行
1. 编译,c++17标准，O2优化
```
g++ sol.cpp -o sol.exe -std=c++17 -O2
```
2. 运行
```powershell
gc in.txt | .\sol.exe
```
3. lower_bound是第一个大于等于某个值的位置,upper_bound是第一个大于某个值的位置

4. 当题目说结果对p取模时,如果只涉及加减乘,可以在每一步都取模(不用管p是不是质数),如果涉及除法,需要先求逆元再取模,此时要求p是质数,否则需要用扩展欧几里得算法求逆元(而且逆元不一定存在)

5. 256MB的内存大约能存5e7个int,内存开大了是非常危险的,很可能直接导致RE或MLE导致一个点都过不了
